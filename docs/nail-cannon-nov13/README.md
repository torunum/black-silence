# Nail Cannon: the brass cassette

[Compare the reload](reload-comparison.png): baseline above, revised below. From left to right, each row shows the same HUD crop at 12%, 22%, 40%, 67% and 94% of a real keyboard reload. [Full extraction frame](cassette.png).

The support hand reaches the cassette before it turns to unlock. Hand and cassette move away from the open copper-rimmed socket together, seat, and return to the normal hold. The rear grip uses a mask from the [approved Nail Cannon reference panel](../../assets/weapon-reference/arsenal-target-6-9-v1.png). Independent review rejected alternative tube models that lost the pitted metal artwork; the original barrel assembly and spin have been kept.

[Verification](verification.json) includes four reload endpoints (dense and aspect passes), rendered output checks for the nine other weapons, native held-fire samples and serial reload timings. All images were produced by the private weapon-only build identified in that file.
